# ==========================================
# External System & Infrastructure Dependencies
# ==========================================
# The following software must be installed on your machine or server:
#
# 1. Redis Server
#    - Required by Celery for message brokering and task queuing.
#    - Windows: Install via WSL or use Memurai/Docker.
#    - Mac/Linux: `sudo apt install redis` or `brew install redis`.
#
# 2. Database
#    - SQLite: Built-in with Python, used by default (no install needed).
#    - PostgreSQL: If deploying to production, a Postgres instance is required.
#
# 3. Frontend
#    - The frontend uses Vanilla HTML/CSS/JS and is served directly by FastAPI from the `static/` folder.
#    - Chart.js is loaded dynamically via CDN.
#    - No Node.js or npm installation is required to run the frontend.
