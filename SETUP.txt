AlgoPharma Setup Guide

This guide will walk you through setting up the AlgoPharma project on your local machine.

Prerequisites

- Python 3.x
- Node.js and npm
- Docker
- Git

Installation Steps

1. Clone the Repository

git clone https://github.com/Ankur2606/Algo-Pharma
cd Algo-Pharma

2. Install UV Package Manager

pip install uv

3. Sync Python Dependencies

uv sync

4. Setup Redis (Docker)

Start a Redis container with a custom name:

docker run -d --name redis-algopharma -p 6379:6379 redis:alpine

Managing Redis Container:

- Stop: docker stop redis-algopharma
- Start: docker start redis-algopharma
- View logs: docker logs redis-algopharma

5. Setup Frontend

Navigate to the frontend directory and install dependencies:

cd frontend
npm install

Running the Application

You'll need to run three services simultaneously. Open separate terminal windows for each:

Terminal 1: Backend API Server

uv run uvicorn main:app --reload --port 8000

The API will be available at http://localhost:8000

Terminal 2: Celery Worker

uv run celery -A celery_app worker --loglevel=info --pool=solo

Terminal 3: Frontend Development Server

cd frontend
npm run dev

The frontend will be available at the URL shown in the terminal (typically http://localhost:5173)

Access Points

- Backend API: http://localhost:8000 - API interaction and documentation
- Frontend: Check terminal output for the dev server URL
- Redis: localhost:6379

Notes

- The backend at port 8000 is fully functional for API interactions
- Make sure Redis is running before starting the Celery worker
- All three services (API, Celery, Frontend) need to be running for full functionality

Troubleshooting

- If Redis fails to start, check if port 6379 is already in use
- If the frontend fails to start, ensure all npm dependencies are installed
- Check individual service logs for specific error messages
